# Thư mục video

Đặt clip giới thiệu phố cổ vào đây với tên **`gioi-thieu.mp4`** (định dạng MP4, H.264).
Game sẽ tự phát clip này trên điện thoại của nhân vật ở cảnh mở đầu.
Nếu chưa có file, game dùng video hoạt hình có sẵn.

Lưu ý: GitHub giới hạn mỗi file 100 MB; nên nén clip dưới khoảng 50 MB để tải nhanh.
